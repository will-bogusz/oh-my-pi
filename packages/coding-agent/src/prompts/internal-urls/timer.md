`timer://`: this machine's timers; `timer://<id>` card + prompt; `timer://<id>/runs` history, `timer://<id>/runs/<seq|latest>` one run + its log (+ `result.json` for fresh/own agent runs); write `timer://<id>/fire` (content = data for the run, untrusted), `timer://<id>/edit` (content = JSON of the fields to change: `reason`, `at`, `every`, `when` (`{"cmd"|"ci"|"pid": …}`, a condition replacing the schedule), `tz`, `prompt`, `shell`, `whenClosed`, `cwd`, `expires`, `maxRuns`, and for fresh/own runs `model`, `agent`, `thinking`, `hermetic`, `maxTime`, `maxCost`, `expect`, `before`, `after`, `report`; e.g. `{"at":"in 3h"}`), `/pause`, `/resume`, `/remove` (omit `content`).
